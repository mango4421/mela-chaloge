# Mela — Ek shaam, bachpan ke naam

A mobile-first Dussehra evening built with HTML, CSS and JavaScript. No build step or runtime dependencies.

Serve this directory with any static server. Swipe or use A/D and arrow keys to move between eight stops. All games, virtual toys and digital food memories are free.

## Included

Generated mela panorama, free balloon and ring games, synthesized opt-in crowd/dhol ambience, jhoola animation, recorded Ram Leela YouTube embed with external fallback, visual-only fireworks, symbolic Ravana Dahan, native sharing/clipboard fallback, and downloadable PNG invitation card. Reduced-motion mode and keyboard-accessible dialogs are included.

## Support

Set the public ID/link in `payment-config.js`. The daan patra is deliberately disabled until the creator provides a public Razorpay Payment Button ID or hosted payment link. Never imply physical purchases or delivery. Optional support/tips must remain separate from free gameplay and souvenirs.

## Media

`assets/mela-panorama.png` generated with the built-in image generation tool. Prompt: ultrawide cinematic painterly 3D miniature nighttime Indian Dussehra fair; navy/teal sky, amber marigold lights, entrance left, toy/balloon/chaat stalls center, ferris wheel and Ram Leela stage right, Ravana far right; nostalgic handcrafted textures; no text/logos/watermark.

Ram Leela video is the recorded cultural film embedded on Sangeet Natak Akademi's Ramlila heritage page: https://indiaich-sna.in/ramlila-the-traditional-performance-of-the-ramayana . YouTube availability is controlled by the publisher. Ambience is synthesized using Web Audio; no recordings or copyrighted songs included.
